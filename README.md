# 베르넬 (Bernel)

3D 쿼터뷰 액션 MMORPG 「베르넬」의 **수직 단면(vertical slice)** 입니다.
설계 기준은 `D:\Game\베르넬_v0.3_통합설계_개정안.md` (**v0.3 제안 기준** — 확정 설정 아님) 입니다.

> 선택받은 영웅은 없습니다. 플레이어는 끊어진 다리 때문에 붐비는 하르벤 교역 거점에 도착한 한 사람이고,
> 호위·제작·조사 중 원하는 방식으로 일하거나, 아무 일도 맡지 않을 수 있습니다.

## 실행

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # dist/ 배포용 빌드
npm run test:logic # 렌더러 없이 게임 로직만 Node 에서 검증 (직업·교역로 3경로·다리 상태·저장 이관)
```

## 캐릭터 생성
- **이름 · 출신 · 전투 직업**을 따로 고릅니다. 수선공 연맹 가입은 선택(하일라에게 문의, 거절해도 불이익 없음).
- **출신 5종**: 농가 출신 / 항구 노동자 / 공방 견습 / 유랑민 / 폐허 정착민 — 전투 능력은 같고 시작 소지품·소개 대사만 다름.
- **전투 직업 4종** (단면 범위, 수치는 모두 검증 전 예시)

| 직업 | 무기 실루엣 | 자원 (획득 → 소모 → 고갈) | 기본 공격 | 대표 기술 (Q/W/E) |
|---|---|---|---|---|
| 수호기사 | 대형 방패·짧은 창·낮은 자세 | 결의: 정면 막기·찌르기 적중 → 호위 교대/성벽 전개/반격 → 비전투 시 감소 | 창 찌르기 | 방패 세우기 · 호위 교대 · 성벽 전개 |
| 매듭궁수 | 장궁·화살통·조준선 | 표식: 표식 화살로 적에게 최대 3 → 연결 사격이 소모 → 10초 뒤 소멸 | 사격(근접 시 약화) | 표식 화살 · 연결 사격 · 매듭 이동 |
| 원소직조사 | 지팡이·회전 문양판 | 원소식 3칸: 불씨/서리선이 채움 → 완성 문양이 소모 → 8초 뒤 흩어짐 | 문양탄 | 불씨 · 서리선 · 완성 문양 |
| 생명염색사 | 염료병·도포봉·앞치마 | 안료 100: 회복·보호에 소모 → 서서히 재생 → 바닥나면 회복 불가 | 도포봉 치기 | 초록 도포 · 번지는 빛 · 색 빼기 |

- 모든 직업 공통 자가 생존 수단: **구르기(Space, 짧은 무적)**.
- 직업 변경: **안전 거점 안 + 비전투 + 호송 중 아님**일 때 「임시 공개 교육 담당자」에게서. 주간 제한 없음, 레벨·기록 유지.

## 하르벤의 끊어진 교역로 (v0.3 §9.4)
세 계약 중 하나를 맡고, 도중에 다른 계약으로 바꿀 수 있습니다. 수락 전에 **제한시간·실패 결과·포기 비용·보상**을 보여줍니다.

| 계약 | 의뢰인 | 방식 | 흐름 |
|---|---|---|---|
| 수레 호위 | 벨로 하르크 | 전투 | 우회로 위험 생물 4 처치 → 벨로에게 **부상자/화물 선택** → 수레를 상류 여울 건너 동쪽 창고까지 호송 (10m 안에 있어야 수레가 움직임, 매복 있음) |
| 장치 수리 보조 | 현지 상인 | 제작 | 목재 더미·수레 잔해에서 채집 → 작업대에서 보강 부품 2개 조립 → **납품(공공 기여) 또는 판매(골드만)** |
| 실종 가축 조사 | 하일라 몬티스 | 탐험 | 단서 3곳 조사(피격 시 끊김) → 하일라에게 **공개 공지 / 지부에만 보고** 선택 |

- **공공 결산**: 호송 안전·수리 자재·조사 진행 + 교량 조(NPC)의 꾸준한 작업을 합산 → 다리가 `끊어짐 → 임시 교량 또는 임시 우회로 → 정식 복구`로 눈에 보이게 바뀝니다. 상류 여울은 어느 상태에서도 건널 수 있습니다(핵심 접근 보장).
- 캐릭터별 경로 기여 한도, 판매와 납품 구분, 접속하지 않은 동안에도 NPC 진행(상한 있음). 진행 중 계약은 저장하지 않으며 다음 접속에 벌칙 없이 다시 시작합니다.
- **개인 결과**: NPC 기억 태그(예: 벨로 ‘부상자 우선’, 하일라 ‘공지 공개’, 모라 ‘감정 조작 요청’)가 다음 대화의 첫 줄을 바꿉니다.
- 모라의 **응급 치료는 관계와 무관하게 항상** 제공됩니다. 감정 조작 부탁은 신뢰가 높아도 거절합니다.

## 살아 있는 거점 · 관계 (v0.3 제안 기준)
- **하루 시계**: 게임 하루 = 실제 20분 (`src/data/households.js` CLOCK). 시간에 따라 해·하늘·그림자가 바뀌고, HUD 오른쪽 위에 시계.
- **일과**: 하일라(명부 정리 → 화물 명세 확인 → 다리 공사장 점검), 벨로(훈련장에서 수련생 훈련), 모라(진료 → 오후 약초 채집), 상인(짐 채우기 → 좌판 → 흥정)이 길 그래프를 따라 걸어 다니며 직업 동작(KayKit 클립)을 한다. 욕구(배고픔·휴식·사교·일 만족)가 높으면 일과에서 벗어난다.
- **직업 결과가 세계에 반영**: 모라와 마렌의 약초 → 진료소 결 연고(하루 1개), 교역로(다리) 상태 → 상인 재고·장비값.
- **가족**: 하르크 가족(벨로·리세·토비), 데일 가족(오렌·마렌 — 양을 잃은 농가), 방앗간 숙소(짐꾼 페드·수련생 카이). 함께 먹고, 저녁엔 보호자가 아이를 데려가고, 아이가 다치면 진료소로 간다. 주민끼리 가까우면 말풍선 잡담.
- **필수 기능은 항상**: 밤이거나 집에 있거나 반감이 커도 창구(연맹 계약 게시판·호위 모집판·진료소 종·좌판 장부)에서 대신 응대한다.
- **접속하지 않아도 벌칙 없음**: 시계만 진행하고 관계 수치는 줄지 않는다.

### 친밀도 쌓기
| 방법 | 내용 |
|---|---|
| 오늘의 대화 | 하루 한 번 신념에 관한 질문. 공감하든 반박하든 **교감도**가 오른다 |
| 선물 | 좋아함/싫어함 범주, 같은 물건은 점점 덜 반김, 하루 3번 |
| 일 돕기 | 그 사람이 일하는 중일 때: 상자 나르기·약초 캐기·수련생 대련·화물 명세 확인 (하루 1번, 30~90초) |
| 가족 돕기 | 주민의 작은 부탁 → 관련 인물에게도 번짐 |
| 약속 | 계약을 끝내면 신뢰 +, 포기하면 신뢰 − (기억 태그로 남음) |
| 교역로 선택 | 부상자/화물, 공지 공개/지부 보고 등 |

- 대화창 오른쪽 관계 패널: 친밀도·교감도·반감도·신뢰, 단계(낯섦→안면→호의→신뢰→각별 / 경계·불편·적대), 최근 기억 3개.
- 단계가 오르면 특별한 대사 배너와 편지. 상인은 친밀도에 따라 최대 5% 할인.
- **금지선**은 친밀도가 최대여도 바뀌지 않는다 (예: 모라는 감정 조작을 하지 않는다).
- **K — 인연 창**: 사람들, 관계 단계, 지금 있는 곳, 가족, 알게 된 취향.

### 히든 퀘스트 (목록에 미리 보이지 않음)
친밀 「신뢰」 이상 + 교감도 조건(+ 때로는 세계 상태·시간대)을 만족하면 그 인물이 따로 말을 건다 (머리 위 ✦).
「철수 명령의 진실」(벨로) · 「고치지 않은 환자」(모라) · 「명부에서 지워진 이름」(하일라, 실종 가축 조사 완료 필요) · 「밀수 화물」(상인, 다리가 끊어지지 않은 상태).
보상은 외형·칭호·처방전 등 (전투력 독점 없음). 포기 선택지가 있다.

## 지도 · 질주
- **M — 세계 지도**: 수놓은 천 지도. 가 본 곳만 보이고 나머지는 양피지 안개. 만난 사람의 지금 위치, 거점·다리 상태·상점·훈련장·진료소, 진행 중 계약 목표, 찾은 단서, 위험 지역, 범례. 휠 확대·드래그 이동·클릭으로 목적지 표시(미니맵과 화면 화살표에 나타남). 게임은 멈추지 않는다.
- **Shift — 질주**: 이동 속도 1.6배, 기력 소모(전투 중 더 빨리). 구르기도 같은 기력을 쓴다. 0이 되면 20% 회복할 때까지 질주 불가. 수치는 `src/data/feel.js` move.
- **F9**: 타격감 시험용 허수아비 (공격하지 않음).

저장 형식 v3 (v2 → v3 이관: 관계 축은 기억 태그에서 추정, 탐험·시계·히든 퀘스트는 새로 시작).

## AI 생성 3D 에셋 추가하기 (TRELLIS 파이프라인)
1. `public/models/ai/<id>.glb` 에 파일을 넣는다. ID는 `tools/ai3d/pipeline.py` 의 ASSETS 이름과 같다.
   (정적 메시 · 뼈대/애니메이션 없음 · 높이 1.0 정규화 · 원점 중심 · Y-up)
2. 목록 `src/data/aiAssets.js` 의 `AI_ASSETS` 에 이미 있는 ID면 **아무것도 고칠 필요 없다** — 다음 실행에 자동으로 나타난다.
   새 ID라면 `{ role, height | fit, rotY, yOffset }` 한 줄을 추가한다. 정면이 맞지 않으면 `rotY` 로 보정.
3. 쓰이는 곳
   - `class_*`: 캐릭터 생성 화면 턴테이블(컨셉아트 `public/art/concept/<id>.webp` 가 카드 배경). 리그가 없어 플레이어 본체로는 쓰지 않는다(플레이어는 KayKit 리그).
   - `npc_*`: 거점 NPC. 없으면 `class_*` 모델을 색조를 바꿔 대역으로 사용(`NPC_AI`). 숨쉬기(세로 ±1%)와 대화 시 플레이어 바라보기.
   - `prop_*`: 공동 베틀·물레방아·집(거점 중심 3채)·끊어진 다리(끊어짐/우회로 상태에만)·호송 수레. 절차적 버전은 숨겨 둔 채 대체용으로 남는다.
   - `weapon_* / armor_* / artifact_* / item_thread_ball`: 바닥 드롭(빛나며 회전) + 상점·소지품 3D 아이콘(한 번 렌더해 캐시). 매핑은 `ITEM_AI`.
4. 성능: 한 번에 올리는 무거운 메시 종류는 7개까지(`AI_MAX_HEAVY`), 5MB가 넘는 파일은 콘솔 경고. 불러온 모델은 캐시 후 복제해서 쓴다.
   **F3** 로 그래픽을 낮추면 후처리와 AI 모델을 끄고 절차적 대체 모델을 쓴다.
5. 파일이 없거나 깨져 있으면 오류 없이 대체 모델을 쓴다 (`npm run test:logic` 9번 항목이 이를 확인).
